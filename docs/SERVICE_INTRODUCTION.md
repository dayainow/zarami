# 자람이 (Zarami) 서비스 기획 및 소개서

## 1. 서비스 개요 (Overview)
**Zarami(자람이)**는 단순한 지식 학습용 퀴즈나 추상적인 체크리스트를 넘어, **"실제 채용 공고(JD) 스펙을 기반으로 로드맵을 그리고, 학습 후 실제 입사 지원까지 직결되는 실전 지향형 커리어 가이드 & 포트폴리오 빌더"**입니다. 
딱딱한 개발 로드맵을 픽셀 아트 기반의 RPG 게임 세계관으로 풀어내어 몰입감을 극대화했습니다.

## 2. 타겟 유저 (Target Audience)
- **주 타겟**: "어떤 기술을 더 배워야 이직할 수 있을까?" 고민하는 주니어 ~ 미들급 '찐개발자'
- **서브 타겟**: 트렌디한 IT 기업(네카라쿠배, 유니콘 스타트업 등)의 실무 기술 스택을 파악하고 싶은 취업 준비생

## 3. 핵심 가치 (Core Flow & Identity)
1. **정확한 채용 스펙 트렌드 추출**: 원티드, 점핏 등 실제 채용 사이트들의 최신 JD 데이터를 분석하여 시장에서 정말로 원하는 스킬을 찾아냅니다.
2. **트렌드 기반 로드맵 생성**: 추상적인 'React 배우기'가 아닌, 실제 기업이 요구하는 수준에 맞춘 커리어 트리를 제공합니다.
3. **증명된 실력 (Evidence-based)**: 단순히 버튼을 눌러 완료하는 것이 아니라, GitHub 코드를 연동하여 실력을 증명합니다.
4. **학습에서 채용 지원으로 연계**: 부족한 스킬을 채운 뒤, 최종적으로 채용 사이트에 실제로 지원하는 플로우를 매끄럽게 연결합니다.

## 4. 주요 기능 (Key Features)

### ⚔️ 1. 타겟 JD 기반 "2주 완성 단기 스프린트" 생성 (Gap Analysis)
사용자가 가고 싶은 회사(예: 토스, 당근마켓)의 실제 채용 공고(JD)를 복사하여 붙여넣으면, AI가 사용자의 현재 스킬과 비교하여 **기술적 Gap을 냉정하게 분석**합니다.
- **하드코어 미니 프로젝트**: "상태관리 공부하기" 같은 뻔한 내용 대신, "2주 동안 Zustand를 활용한 장바구니 동시성 처리 프로젝트 구현하기" 등 이력서에 바로 쓸 수 있는 실전 퀘스트를 내려줍니다.
- **면접 대비 리뷰 포인트**: 해당 스킬에 대해 면접관이 물어볼 만한 압박 질문들을 미리 제공하여 면접 방어력을 높입니다.

### 🛡️ 2. "내 실력을 증명하라!" GitHub 인증 (Skill Verification)
체크박스 클릭 하나로 스킬을 획득하는 것을 신뢰하지 않는 '찐개발자'들을 위한 기능입니다.
- 스킬 트리(월드맵)에서 특정 노드(퀘스트)를 완료하려면, **해당 기술을 구현한 본인의 GitHub Repo URL이나 PR(Pull Request) 주소**를 제출해야 합니다.
- 링크가 제출된 노드는 '인증된(Certified)' 상태로 변경되며, 이는 추후 이력서의 포트폴리오 증빙 자료로 강력하게 활용됩니다.

### 🗺️ 3. 픽셀 아트 RPG 세계관의 스킬 트리 (World Map)
개발자의 성장 과정을 게임의 스킬 트리를 찍고 미지의 세계를 탐험하는 과정으로 시각화했습니다.
- 과녁, 교차된 검, 보물상자 등 32비트 픽셀 아트 에셋을 활용하여 게이미피케이션(Gamification) 요소를 강화했습니다.
- 시각적인 즐거움과 성취감을 동시에 제공합니다.

### 📈 4. 실시간 스킬 채용 지표 (Trends)
"요즘 프론트엔드에서는 GraphQL이 대세일까, tRPC가 대세일까?"
- 수만 건의 채용 공고를 분석하여, 각 스킬이 실제 채용 시장에서 얼마나 자주 언급되는지 객관적인 수치(Mention Count)로 보여줍니다.
- 트렌딩 스킬을 클릭하여 곧바로 내 로드맵의 서브 퀘스트로 추가할 수 있습니다.

## 5. 향후 확장 계획 (Roadmap)

1. **'네카라쿠배' 자체 채용 포털 크롤러 (프리미엄 기능)**
   - 대형 테크 기업들(네이버, 카카오, 라인, 쿠팡, 배민, 토스)의 자체 채용 사이트 API를 리버스 엔지니어링하여, 최상위 IT 기업들만의 은밀한 기술 트렌드를 분석합니다.
2. **실전 압박 면접 (AI Mock Interviewer)**
   - 스킬 노드를 클리어하기 위한 최종 관문으로, AI 챗봇과 해당 기술에 대한 실무 면접을 진행하고 통과해야만 인증 마크를 부여합니다.
3. **이력서(Resume) / 포트폴리오 자동 Export**
   - 자람이에서 달성한 스킬 트리와 GitHub 인증 내역, 트러블슈팅 경험을 모아서 노션(Notion) 이력서 템플릿이나 마크다운 형태의 제출용 포트폴리오로 자동 컴파일해 줍니다.
