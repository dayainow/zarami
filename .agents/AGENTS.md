# Zarami (자람이) 핵심 정체성 및 기획 기준 (Core Identity)

본 프로젝트의 모든 기능 개발, UI/UX 설계, 코드 작성 시 아래의 "핵심 기준"을 반드시 최우선으로 고려하고 참고해야 합니다.

## 핵심 기준 (The Core Flow)
1. **정확한 채용 스펙 트렌드 추출:** 채용 사이트들의 최근 실제 채용 스펙 트렌드를 정확하게 가져온다.
2. **트렌드 기반 로드맵 생성:** 그 정확한 채용 정보를 기반으로 현실적인 커리어 로드맵을 만든다.
3. **학습 동기 및 목표 부여:** 유저가 이 스펙을 왜 배워야 하는지, 무엇을 해야 하는지 명확히 깨닫게 한다.
4. **실제 채용 지원 연계:** 부족한 스킬을 채운 뒤, 최종적으로 채용 사이트에 **실제로 지원하는 플로우**를 매끄럽게 연결한다.

**정체성 요약:** 
"단순한 지식 학습용 퀴즈나 추상적인 증명보다는, 실제 채용 공고 스펙을 기반으로 로드맵을 그리고, 학습 후 실제 입사 지원까지 직결되는 실전 지향형 커리어 가이드 서비스"
